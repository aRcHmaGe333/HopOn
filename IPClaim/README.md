
# IPClaim


**Intellectual Property Claim for An Era of Progress**

IPClaim is a repo toolkit and proof model for publishing authorship claims as public, timestamped, independently verifiable records. IPClaim provides both the proof system and the reference implementation—there is no separate service or bundling layer.

## The statement:

> **Universal, Evidence-Based IP Claim**

> I claim, as my intellectual property, whatever can be claimed and has not been previously claimed as IP by another. I do not need to specify in advance which parts of my work qualify as IP, nor do I need to hire experts, clerks, or lawyers to determine this for me. By publishing this work, I assert that all content disclosed herein—if and to the extent it qualifies as previously unclaimed intellectual property - is hereby claimed by the author, with the combined timestamp and contents of disclosure provided as immutable, cryptographic evidence. 

## IPClaim: Meta-Proof - Your work is its own witness

IPClaim replaces traditional paperwork and gatekeeping with cryptographic certainty. Your work is its own ID, stands as its own testament — timestamped, verifiable, and enduring.
- Proof embedded in your code, blueprint, disclosure
- Authorship verifiable by anyone, anywhere
- Ownership based on evidence

One system is based on evidence. The other is based on permission.

## How to Claim IP in Your Work (Automated)

This folder contains templates and a reference implementation for maintainers who want to add cryptographic timestamping and the APC license to a repository.

Important: the stamping process modifies the target repository (it copies license files, adds a workflow, commits, and may push). Do NOT run the stamping scripts unless you are an authorized repository maintainer and you understand the consequences.

See `QUICKSTART.md` for a concise, maintainers-only quickstart (POSIX and PowerShell examples) and guidance on safe operation.
